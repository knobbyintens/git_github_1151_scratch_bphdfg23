# Open Source Portfolio Register

Quarterly register of open-source projects maintained by the Applied Systems Group.

The machine-readable register is `portfolio/register.json`.

Field notes:

- `project_dir` is the directory under `projects/` that holds the project's code.
- `paper_url` is the arXiv abstract URL for the project's paper.
- `repository_url` is present only when the project's code is publicly available.
