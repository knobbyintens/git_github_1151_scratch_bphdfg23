# Nova Workspace

Nova Workspace is the internal collaboration platform used by the engineering,
support and revenue teams.

## Repository layout

- `CHANGELOG.md` — release queue and shipped history
- `docs/architecture.md` — service map and ownership
- `CONTRIBUTING.md` — contribution and review rules

## Release process

Each release cut starts with a triage of the `CHANGELOG.md` release queue
against the issue tracker. The release manager opens a short-lived branch,
updates the queue, and lands the change through a pull request.
